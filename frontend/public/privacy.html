Privacy policy

Last updated 11 November 2026

CodePilot is a student project that reviews source code with an AI model. This page says what the site stores about you and why.

What we store

  • Your account. Sign-in is handled by Clerk. Clerk holds your email address and, if you use Google sign-in, the name and email Google shares. We keep only the account ID Clerk gives us.
  • Your reviews. When you ask for a review, we save the file name, its language, the code you submitted, the findings and the rewritten code, so you can reopen it from your history.
  • Usage counts. We count how many reviews you have run, to apply the review limit, and note when you first and last used the site.
  • On your device. Your browser remembers the code you are editing and your light or dark theme, so a refresh does not lose them. This never leaves your device.

Where your code goes

Code you submit is sent to the AI model that writes the review, which runs on servers operated by this project. It is not sold, shared with advertisers or used to train a model. Don’t submit code that contains passwords, keys or other secrets.

Who else handles the data

Cloudflare hosts the site, Clerk handles sign-in, and Supabase hosts the database. Each processes data only to provide that service.

Deleting your data

You can delete any saved review from your history at any time. To delete your account and everything stored with it, email the address below.
